# M0 demo — Foundation

Prerequisites: Node ≥ 22 (`.nvmrc` = 22), pnpm 11, Docker running.

```bash
cp .env.example .env        # first time only
pnpm install
pnpm db:reset               # starts Postgres 16 (localhost:15432), migrates, loads db/003 dev seed
pnpm dev                    # db + migrate + api (http://localhost:18080) + web (http://127.0.0.1:15173)
curl http://localhost:18080/health      # {"status":"ok","checks":{"db":"ok"}}
```

The ports (15432 / 18080 / 15173) are deliberately unusual because common dev ports are often taken. Change `DB_PORT`, `PORT` and `DATABASE_URL` in `.env` if needed.

## Verify

```bash
pnpm lint && pnpm typecheck && pnpm test
```

`pnpm test` starts throwaway Postgres 16 containers (Testcontainers) and proves:

- payments: UPDATE/DELETE blocked, replayed idempotency key rejected, non-positive amount rejected
- settled bills: money/status edits and DELETE blocked, bookkeeping columns (fiscal, print_count) still writable, `bill_lines` frozen
- overpayment blocked (single tender, multi-tender, after settle); bill arithmetic constraint enforced
- one open/billed order per table; one open business day per branch
- `audit_log` and `khata_entries` append-only
- migration files are byte-identical to the reference SQL in `db/`
- phase-2 migration applies on a DB that already has data; `stock_movements` immutable

## Other commands

| Command                    | What it does                                                   |
| -------------------------- | -------------------------------------------------------------- |
| `pnpm db:migrate`          | apply core migrations (forward-only)                           |
| `pnpm db:migrate:phase2`   | apply inventory/purchasing schema (db/002) — not needed yet    |
| `pnpm db:codegen`          | regenerate Kysely types from the migrated DB                   |
| `pnpm db:reset`            | **dev only**: drop/create DB, migrate, seed (refuses non-local) |
| `docker compose --env-file .env -f ops/docker-compose.yml up -d` | production-like stack (DB port not published) |
